## 회귀 점검표

AGENTS.md의 확인 절차와 완료 기준 ①~⑤를 바탕으로 만든 점검표입니다. 기능을 고친 뒤 같은 Chrome 브라우저와 같은 주소(포트 포함)에서 위에서부터 차례로 확인하고, "결과" 칸은 직접 채웁니다.

- 완료 기준 ①: 선수 선택 + 영상 재생 시 포커스 테두리가 위치 데이터를 따라 움직인다.
- 완료 기준 ②: 영상이 끝나면 경기 종료 화면으로 자동 이동하고 기록·하이라이트가 보인다.
- 완료 기준 ③: 하이라이트 영상 참조와 설명을 저장하면 목록에 나타나고 새로고침해도 남는다.
- 완료 기준 ④: 영상 미선택, 빈 설명, 공백뿐인 설명은 오류를 표시하고 저장하지 않는다.
- 완료 기준 ⑤: 예시 영상을 1분간 볼 때 멈춤·로딩 표시 없이 포커스가 선수를 따라간다.

준비: 현재 저장소 터미널에서 `flutter run -d chrome`으로 실행하고, 하이라이트 점검 전에는 개발자 도구 Application 탭에서 `localStorage`를 비워 둔다. 포커스 위치 데이터가 있는 선수는 아르다 귈러(0:23.5~0:32.0, 3:09.0~3:17.5 구간)뿐이므로 포커스 점검은 이 선수로 한다.

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
|---|---|---|---|---|
| 0 | 콘솔 오류 없음 | 앱을 실행한 뒤 개발자 도구(macOS: Cmd+Option+I)의 Console 탭을 연다. 선수 선택 → 영상 재생 → 종료 화면 → 하이라이트 저장까지 한 번 진행하면서 Console을 계속 본다. | 앱 실행과 관련된 빨간 오류가 없다. (youtube_player_iframe 응답 형식 오류가 보이면 실패로 기록한다.) | |
| ①-1 | 선수 선택 | 첫 화면에서 아르다 귈러를 누른다. | 선택 표시가 한 명에게만 나타나고 시청 화면으로 이동한다. | |
| ①-2 | 포커스 테두리 이동 | 시청 화면에서 영상을 재생하고 0:23.5~0:32.0 구간을 지켜본다. 이어서 3:09.0~3:17.5 구간도 본다. | 두 구간 동안 테두리가 영상 속 튀르키예 10번을 따라 움직인다. | |
| ①-3 | 위치 미등록 구간 표시 | 위 두 구간 밖(예: 1:00 부근)에서 화면을 본다. | 테두리를 임의로 그리지 않고 "위치 미등록" 상태가 표시된다. | |
| ①-4 | 시청 중 선수 변경 | 재생 중에 다른 선수를 누른다. | 선택 표시와 포커스 대상이 바뀌고 영상은 끊기지 않는다. 위치 데이터가 없는 선수는 위치 미등록으로 표시된다. | |
| ①-5 | 시청 중 경기 정보 | 선수를 바꿔 가며 이동 거리, 골, 어시스트, 패스 표시를 본다. | 네 항목이 표시되고, 출처에 기록된 실제 수치와 같다. 확인되지 않은 수치는 "자료 없음"으로 나온다. | |
| ②-1 | 영상 종료 시 자동 이동 | 영상을 끝까지 재생(또는 끝 부근으로 이동)하고 종료까지 기다린다. | 사용자가 누르지 않아도 경기 종료 화면으로 자동 이동한다. | |
| ②-2 | 종료 화면 기록 | 종료 화면에서 선택한 선수의 득점·도움·출전 시간과 하이라이트 영역을 본다. | 세 기록과 하이라이트가 표시되고, 선택하지 않은 선수의 기록은 나오지 않는다. | |
| ③-1 | 하이라이트 저장 | 종료 화면에서 영상 참조로 "0:23.5~0:32.0 구간"을 고르고 설명에 "압박 후 공을 되찾는 장면(예시)"을 입력해 저장한다. | 저장한 영상 참조와 설명이 목록에 나타난다. | |
| ③-2 | 하이라이트 재생 | 목록 또는 선택한 구간의 재생 버튼과 다시 재생 버튼을 차례로 누른다. | 해당 구간이 재생되고, 다시 재생하면 구간 처음부터 재생된다. | |
| ④-1 | 영상 미선택 | 영상 참조를 고르지 않은 채 설명에 "예시 장면"을 입력하고 저장한다. | 오류 문구가 표시되고 목록에 추가되지 않는다. | |
| ④-2 | 빈 설명 | 영상 참조는 고르고 설명 칸은 비워 둔 채 저장한다. | 오류 문구가 표시되고 목록에 추가되지 않는다. | |
| ④-3 | 공백만 입력 | 영상 참조는 고르고 설명 칸에 스페이스만 여러 번 입력한 뒤 저장한다. | 빈 설명과 같은 오류가 표시되고 목록에 추가되지 않는다. | |
| ④-4 | 정상 설명 | 영상 참조를 고르고 설명에 "전반 첫 패스 장면(예시)"을 입력해 저장한다. | 오류 없이 목록에 추가되고 입력 칸이 비워진다. | |
| ⑤-1 | 새로고침 후 하이라이트 유지 | ③-1과 ④-4로 두 개를 저장한 뒤 같은 Chrome 탭·같은 주소에서 새로고침한다(macOS: Cmd+R). | 새로고침 후에도 두 개의 영상 참조와 설명이 같은 순서로 남아 있다. | |
| ⑤-2 | 저장 범위 확인 | 개발자 도구 Application 탭의 `localStorage`와 Network 탭을 연다. 하이라이트를 하나 더 저장하고 두 곳을 본다. | `localStorage`에는 영상 참조·설명·포커스 위치 기록만 있고 영상 파일은 없다. 저장 시 외부로 나가는 요청이 없다. | |
| ⑤-3 | 브라우저 창 다시 열기 | Chrome 탭을 닫고 같은 주소(같은 포트)로 다시 연다. | 저장한 하이라이트 목록이 그대로 남아 있다. | |
| ⑤-4 | 1분 연속 시청 | 아르다 귈러를 선택하고 0:23.5 구간 직전부터 1분간 재생하며 화면을 관찰한다. | 영상이 멈추지 않고 로딩 표시가 나타나지 않으며, 위치 데이터가 있는 구간에서는 포커스가 선수를 따라간다. | |
