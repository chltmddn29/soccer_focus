# 프롬프트 설계서

## 1. 목표

축구 경기에서 사용자가 한 명의 선수를 선택하면, 영상 속 해당 선수의 움직임을 따라 포커스 표시가 이동하고 그 선수의 경기 정보를 보여주는 앱을 만든다. 경기 종료 후에는 선택 선수의 득점, 도움, 출전 시간과 하이라이트 영상을 보여준다.

최종 목표는 실제 실시간 경기 영상에서 선수를 추적하는 서비스다. 현재는 사용자가 지정한 실제 경기 YouTube 하이라이트를 재생한다. 2026-10-01 사용자 결정으로 선수 이름과 확인된 경기 기록을 실제 자료로 바꾼다. 아르다 귈러를 영상 속 튀르키예 10번의 포커스와 연결한다. 선수 위치는 영상에서 수동으로 기록하고 선수 주위에 테두리로 표시하며, 자동 인식은 하지 않는다.

## 2. 맥락

축구 경기에서 특정 선수를 집중해서 보고, 경기 종료 후 그 선수의 기록과 주요 장면을 확인하는 서비스다. 나는 Dart와 Flutter를 배운 학생이다. 학습용 첫 구현이므로 이해하기 쉬운 구조와 설명을 사용하고, 브라우저에서 기능을 직접 확인할 수 있도록 한다.

## 3. 제약

- 앱 코드는 Flutter와 Dart로 작성하고, 브라우저에서 실행되는 Flutter Web을 대상으로 한다.
- 저장한 영상 참조와 설명은 브라우저의 로컬 저장소에 보관한다. 같은 브라우저에서 같은 주소로 접속하면 새로고침 후에도 유지한다.
- 직접 작성하는 앱 소스 코드는 `.dart` 파일로 제한한다. 실행에 필요한 Flutter 설정 파일과 영상 자산은 허용한다.
- 필요한 외부 패키지는 허용하되, 사용 목적을 한 줄로 설명한다.
- 이 경기의 실제 출전 선수와 확인된 경기 기록을 사용한다. 선수 위치는 영상에서 수동 기록한다.
- 영상은 사용자가 지정한 YouTube 링크를 공식 iframe 플레이어로 재생한다. 영상 파일은 복제·저장하지 않는다. 실제 생중계 연결과 자동 영상 인식은 후속 개발 범위로 둔다.
- 저장 대상은 앱에 포함된 하이라이트 예시 영상의 참조와 사용자가 입력한 설명이다. 영상 파일 자체는 로컬 저장소에 저장하지 않는다. 영상 참조가 없거나 설명이 공백뿐이면 앱에서 오류를 표시하고 저장을 거부한다.

## 4. 출력 형식

- 만들 파일 목록과 파일마다 역할을 한 줄씩 적는다.
- 화면에 보일 요소를 위에서 아래 순서로 적는다.
- Flutter와 Dart를 배운 학생이 이해할 수 있도록 필요한 설명을 덧붙인다.
- 마지막에 아래 완료 기준을 하나씩 어떻게 확인할지, 브라우저에서 수행할 행동과 화면에 나타날 결과를 적는다.

## 5. 완료 기준

1. 브라우저에서 '아르다 귈러'를 선택하고 지정한 YouTube 영상을 재생하면, 수동으로 기록한 튀르키예 10번의 위치 데이터에 맞춰 포커스 테두리가 이동한다. 위치 미등록 구간과 다른 가상 선수는 테두리를 숨긴다.
2. 경기 종료 화면에 '아르다 귈러'의 득점, 도움, 출전 시간이 표시되고, 하이라이트를 누르면 해당 선수의 주요 장면 영상이 재생된다.
3. 앱에 포함된 하이라이트 예시 영상을 선택하고 설명을 입력한 뒤 저장하면 저장 목록에 나타난다. 같은 브라우저에서 같은 주소의 페이지를 새로고침한 뒤에도 같은 항목을 확인할 수 있다.
4. 영상 미선택, 설명이 빈 문자열인 경우, 설명이 공백뿐인 경우를 각각 확인한다. 저장 버튼을 누르면 오류 안내가 표시되고 저장 목록에 새 항목이 추가되지 않는다.
5. 테스트 환경은 Chrome 브라우저에서 Flutter Web 앱을 실행하고 지정한 YouTube 영상을 재생하는 조건으로 한다. '아무개'를 선택해 1분간 시청할 때 영상이 멈추거나 로딩 표시가 나타나지 않고, 등록한 구간에서 포커스 테두리가 위치 데이터에 맞춰 이동한다. 위치 미등록 구간에서는 숨긴다. 실제 생중계 품질은 별도로 검증한다.

## 8. 첫 구현 결정 (2026-09-30)

사용자 결정에 따라 영상 없이 가능한 선수 선택·변경, 선수별 경기 정보 표시, 경기 종료 기록 미리보기의 세 기능을 먼저 만든다. 기존 `lib/main.dart`에 가상 데이터와 두 화면을 구현하고, `test/widget_test.dart`에서 선택·기록 변경·화면 이동·좁은 화면 동작을 검사한다. 새 파일이나 외부 패키지는 추가하지 않는다.

시청 화면은 제목과 실제 영상·가상 데이터 안내 → 선수 선택 → YouTube 경기 영상 → 선택 선수의 경기 정보 → 경기 종료 기록 미리보기 버튼 순서다. 종료 화면은 선택 선수 이름 → 가상 기록 미리보기 안내 → 득점·도움·출전 시간 → 하이라이트 미확정 안내 → 돌아가기 버튼 순서다.

사용자가 지정한 YouTube 하이라이트를 공식 iframe 플레이어로 앱 안에서 재생하도록 구현했다. 영상은 실제 경기이고 선수 이름과 기록은 가상 데이터다. 영상 종료 시 자동 이동은 현재 코드에 구현되어 있다. 하이라이트 재생과 저장은 후속 구현이다.

후속 포커스 구현: 튀르키예 10번을 대상으로 **0:23.5~0:32.0**, **3:09.0~3:17.5**의 수동 위치를 등록했다. 같은 장면 안의 좌표를 보간하고 구간 밖에서는 숨긴다. 재생·일시정지·탐색은 실제 영상 시간에 맞추며, 선수 변경 때 플레이어를 다시 만들지 않는다. 다른 가상 선수와 영상 전체의 나머지 등장 구간은 위치 미등록 상태다. 포커스는 앱 안의 영상에서 확인하며 YouTube 자체 전체 화면에는 함께 표시되지 않는다.


후속 하이라이트 구현: 아르다 귈러의 종료 기록 화면에서 기존 확인 구간 두 개를 선택하고 YouTube 재생 버튼으로 재생한다. 결과 화면을 유지하고 '이 장면 다시 재생'으로 선택한 시작점부터 재생한다. 다시 재생 시 지정 종료 시간을 넘어가는 실패를 세 번 수정한 뒤, 경기 재생기 정리와 위치 스트림 감시 방식으로 변경했으나 종료 제한은 아직 미검증이다. 다른 선수에게는 미등록 안내를 표시한다. 영상 참조와 설명의 저장·입력 검증 및 같은 주소 새로고침 후 유지는 Chrome에서 확인했다. 종료 화면의 기존 하이라이트 미확정 안내는 장면 선택 목록과 선택 구간의 재생기로 대체한다.

2026-10-01 사용자 수정에 따라 첫 화면의 버튼에서 별도 YouTube 영상 추가 페이지를 연다. 유효한 HTTPS YouTube 주소의 영상 ID와 설명만 저장하고, 새 영상은 전체 영상으로 재생한다. 선수 종료 화면에는 기존 두 장면의 지정 구간 하이라이트만 둔다. 다른 선수에게는 여전히 미등록 안내를 표시한다.


2026-10-01 변경: 최신 사용자 결정에 따라 기존의 가상 선수 이름과 기록을 실제 튀르키예–이탈리아 경기 자료로 대체했다. 선택 선수는 아르다 귈러, 바르쉬 알페르 이을마즈, 오우즈 아이든이다. 득점·도움·출전 시간은 경기 기록으로 표시하고 자료가 불확실한 이동 거리·패스는 '자료 없음'으로 표시한다. 이전 절의 가상 데이터 설명은 당시 구현 기록이며 현재 동작에는 적용되지 않는다. 출처와 수치는 `docs/plan.md` 12절에 적었다.
