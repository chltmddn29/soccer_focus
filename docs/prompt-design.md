# 프롬프트 설계서

## 1. 목표

축구 경기에서 사용자가 한 명의 선수를 선택하면, 영상 속 해당 선수의 움직임을 따라 포커스 표시가 이동하고 그 선수의 경기 정보를 보여주는 앱을 만든다. 경기 종료 후에는 선택 선수의 득점, 도움, 출전 시간과 하이라이트 영상을 보여준다.

최종 목표는 실제 실시간 경기 영상에서 선수를 추적하는 서비스다. 첫 구현에서는 가상 경기 영상과 미리 정의한 선수 위치 데이터를 이용해 실시간 시청과 선수 추적 동작을 시연한다. 포커스는 선수 주위에 표시하는 테두리이며, 선수의 움직임에 맞춰 이동한다.

## 2. 맥락

축구 경기에서 특정 선수를 집중해서 보고, 경기 종료 후 그 선수의 기록과 주요 장면을 확인하는 서비스다. 나는 Dart와 Flutter를 배운 학생이다. 학습용 첫 구현이므로 이해하기 쉬운 구조와 설명을 사용하고, 브라우저에서 기능을 직접 확인할 수 있도록 한다.

## 3. 제약

- 앱 코드는 Flutter와 Dart로 작성하고, 브라우저에서 실행되는 Flutter Web을 대상으로 한다.
- 저장한 영상 참조와 설명은 브라우저의 로컬 저장소에 보관한다. 같은 브라우저에서 같은 주소로 접속하면 새로고침 후에도 유지한다.
- 직접 작성하는 앱 소스 코드는 `.dart` 파일로 제한한다. 실행에 필요한 Flutter 설정 파일과 영상 자산은 허용한다.
- 필요한 외부 패키지는 허용하되, 사용 목적을 한 줄로 설명한다.
- 선수 이름은 '아무개'처럼 가상 이름을 사용하고, 경기 기록과 선수 위치도 가상 데이터를 사용한다.
- 영상은 사용 권한이 있는 가상 경기 예시 영상을 사용한다. 첫 구현의 실시간 시청은 예시 영상 재생으로 시연하며, 실제 생중계 연결과 자동 영상 인식은 후속 개발 범위로 둔다.
- 저장 대상은 앱에 포함된 하이라이트 예시 영상의 참조와 사용자가 입력한 설명이다. 영상 파일 자체는 로컬 저장소에 저장하지 않는다. 영상 참조가 없거나 설명이 공백뿐이면 앱에서 오류를 표시하고 저장을 거부한다.

## 4. 출력 형식

- 만들 파일 목록과 파일마다 역할을 한 줄씩 적는다.
- 화면에 보일 요소를 위에서 아래 순서로 적는다.
- Flutter와 Dart를 배운 학생이 이해할 수 있도록 필요한 설명을 덧붙인다.
- 마지막에 아래 완료 기준을 하나씩 어떻게 확인할지, 브라우저에서 수행할 행동과 화면에 나타날 결과를 적는다.

## 5. 완료 기준

1. 브라우저에서 '아무개'를 선택하고 가상 경기 영상을 재생하면, 미리 정의한 위치 데이터에 맞춰 포커스 테두리가 해당 선수의 움직임을 따라 이동한다.
2. 경기 종료 화면에 '아무개'의 득점, 도움, 출전 시간이 표시되고, 하이라이트를 누르면 해당 선수의 주요 장면 영상이 재생된다.
3. 앱에 포함된 하이라이트 예시 영상을 선택하고 설명을 입력한 뒤 저장하면 저장 목록에 나타난다. 같은 브라우저에서 같은 주소의 페이지를 새로고침한 뒤에도 같은 항목을 확인할 수 있다.
4. 영상 미선택, 설명이 빈 문자열인 경우, 설명이 공백뿐인 경우를 각각 확인한다. 저장 버튼을 누르면 오류 안내가 표시되고 저장 목록에 새 항목이 추가되지 않는다.
5. 테스트 환경은 Chrome 브라우저에서 Flutter Web 앱을 실행하고 앱에 포함된 예시 영상을 재생하는 조건으로 한다. '아무개'를 선택해 1분간 시청할 때 영상이 멈추거나 로딩 표시가 나타나지 않고, 포커스 테두리가 선수의 움직임을 따라 유지된다. 이 기준은 가상 영상 시연에 적용하며 실제 생중계 품질은 별도로 검증한다.

## 8. 첫 구현 결정 (2026-09-30)

사용자 결정에 따라 영상 없이 가능한 선수 선택·변경, 선수별 경기 정보 표시, 경기 종료 기록 미리보기의 세 기능을 먼저 만든다. 기존 `lib/main.dart`에 가상 데이터와 두 화면을 구현하고, `test/widget_test.dart`에서 선택·기록 변경·화면 이동·좁은 화면 동작을 검사한다. 새 파일이나 외부 패키지는 추가하지 않는다.

시청 화면은 제목과 가상 데이터 안내 → 선수 선택 → 영상 미확정 안내 → 선택 선수의 경기 정보 → 경기 종료 기록 미리보기 버튼 순서다. 종료 화면은 선택 선수 이름 → 가상 화면 미리보기 안내 → 득점·도움·출전 시간 → 하이라이트 미확정 안내 → 돌아가기 버튼 순서다.

영상 재생과 포커스 이동, 영상 종료 시 자동 이동, 하이라이트 재생과 저장은 후속 구현이다. YouTube 영상 및 임베드 방식을 확정하고 사용 권한과 재생 가능 여부를 확인한 뒤 연결한다.
