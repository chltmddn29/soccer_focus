# 앱 기획서

## 1. 앱 이름

화면 상단 제목은 '축구선수 포커스'다.

## 2. 사용자 (누가 쓰나)

- 축구 경기에서 특정 선수의 움직임을 집중해서 보고 싶은 사용자.
- 경기 종료 후 관심 선수의 기록과 하이라이트를 확인하고, 주요 장면에 설명을 붙여 저장하고 싶은 사용자.
- 첫 구현은 Chrome 브라우저에서 사용하는 Flutter Web 앱으로 만든다.

## 3. 해결할 문제 (왜 필요한가)

경기 영상에서 관심 선수가 어디에 있는지 계속 찾기 어렵고, 그 선수의 경기 기록과 주요 장면을 한곳에서 확인하고 싶다. 사용자가 선수를 선택하면 선수 주위의 포커스 테두리가 움직임을 따라 이동하고, 경기 종료 후 기록과 하이라이트를 보여준다.

최종 목표는 실제 실시간 경기 영상에서 선수를 추적하는 서비스다. 첫 구현은 학습용으로, 사용 권한이 있는 가상 경기 예시 영상과 미리 정의한 선수 위치 데이터를 사용해 동작을 시연한다.

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)

### 꼭 필요한 기능

- '아무개'처럼 가상 이름을 사용하는 선수 선택.
- 가상 경기 예시 영상 재생으로 실시간 시청 시연.
- 영상 재생 시간과 미리 정의한 선수 위치 데이터에 맞춰 이동하는 포커스 테두리.
- 시청 중 선택 선수의 경기 정보 표시.
- 경기 종료 후 선택 선수의 득점, 도움, 출전 시간 표시.
- 선택 선수의 하이라이트 예시 영상 재생.
- 앱에 포함된 하이라이트 예시 영상 선택, 설명 입력, 저장.
- 저장한 영상 참조와 설명을 보여주는 저장 목록.
- 브라우저 로컬 저장소를 이용해 같은 브라우저와 같은 주소에서 새로고침 후에도 저장 항목 유지.
- 영상 미선택 또는 설명이 비어 있거나 공백뿐인 경우 오류 안내 및 저장 거부.

### 있으면 좋은 기능

기존 설계서에서 별도로 정한 선택 기능은 없다. 실제 생중계 연결과 자동 영상 인식은 후속 개발 범위로 둔다.

## 5. 화면 구성 (위에서 아래 순서)

기존 설계서의 기능을 바탕으로 다음 순서로 구성한다.

### 경기 시청 화면

1. 앱 제목과 가상 경기 시연 안내.
2. 선수 선택 영역.
3. 경기 영상과 선택 선수 주위의 포커스 테두리.
4. 영상 재생 조작 영역.
5. 선택 선수의 경기 정보.

### 경기 종료 화면

1. 경기 종료 안내와 선택 선수 이름.
2. 선택 선수의 득점, 도움, 출전 시간.
3. 하이라이트 선택 영역과 영상 재생 영역.
4. 선택한 하이라이트의 설명 입력란.
5. 저장 버튼과 입력 오류 안내.
6. 저장한 하이라이트 참조와 설명 목록.

## 6. 사용 흐름 (사용자가 하는 행동 순서)

1. Chrome 브라우저에서 앱을 연다.
2. '아무개' 등 관심 선수를 선택한다.
3. 가상 경기 영상을 재생한다.
4. 선택 선수를 따라 이동하는 포커스 테두리와 경기 정보를 보며 시청한다.
5. 경기 종료 후 선택 선수의 득점, 도움, 출전 시간을 확인한다.
6. 하이라이트를 선택해 주요 장면 영상을 재생한다.
7. 저장할 하이라이트 예시 영상을 선택하고 설명을 입력한 뒤 저장한다.
8. 저장 목록에서 영상 참조와 설명을 확인한다.
9. 같은 브라우저에서 같은 주소의 페이지를 새로고침해 저장 항목이 유지되는지 확인한다.

## 7. 만들지 않을 것

- 회원가입.
- 로그인.
- 서버 구축 및 연동.
- 다른 사람과 공유하는 기능.
- 첫 구현에서 실제 생중계 서비스 연결.
- 영상에서 선수를 자동으로 인식하거나 추적하는 기능. 첫 구현은 미리 정의한 위치 데이터를 사용한다.
- 실제 선수 이름, 경기 기록, 선수 위치 데이터를 사용하는 기능. 첫 구현은 가상 데이터를 사용한다.
- 영상 파일 자체를 브라우저 로컬 저장소에 저장하는 기능. 하이라이트 영상의 참조와 설명만 저장한다.
- 첫 구현 범위에 별도로 정하지 않은 기능.

구현은 Flutter와 Dart를 사용하며, 직접 작성하는 앱 소스 코드는 `.dart` 파일로 제한한다. 실행에 필요한 Flutter 설정 파일과 영상 자산은 허용한다. 외부 패키지를 사용하면 사용 목적을 한 줄로 설명한다.

## 8. 완료 기준

1. **선수 포커스 이동:** 브라우저에서 '아무개'를 선택하고 가상 경기 영상을 재생하면, 미리 정의한 위치 데이터에 맞춰 포커스 테두리가 해당 선수의 움직임을 따라 이동한다.
2. **경기 기록과 하이라이트:** 경기 종료 화면에 '아무개'의 득점, 도움, 출전 시간이 표시된다. 하이라이트를 누르면 해당 선수의 주요 장면 영상이 재생된다.
3. **저장과 유지:** 앱에 포함된 하이라이트 예시 영상을 선택하고 설명을 입력해 저장하면 저장 목록에 나타난다. 같은 브라우저에서 같은 주소의 페이지를 새로고침한 뒤에도 같은 영상 참조와 설명을 확인할 수 있다.
4. **잘못된 입력 차단:** 영상 미선택, 설명이 빈 문자열인 경우, 설명이 공백뿐인 경우를 각각 확인한다. 저장 버튼을 누르면 오류 안내가 표시되고 저장 목록에 새 항목이 추가되지 않는다.
5. **1분 시청 확인:** Chrome에서 Flutter Web 앱과 앱에 포함된 예시 영상을 실행한다. '아무개'를 선택해 1분간 시청할 때 영상이 멈추거나 로딩 표시가 나타나지 않고, 포커스 테두리가 선수의 움직임을 따라 유지된다. 이 기준은 가상 영상 시연에 적용하며 실제 생중계 품질은 별도로 검증한다.

## 9. 현재 구현 범위 (2026-09-30 사용자 결정)

영상 없이 확인 가능한 다음 세 기능을 먼저 구현했다.

1. 가상 선수 한 명 선택 및 다른 선수로 변경.
2. 선택 선수의 이동 거리, 골, 어시스트, 패스 표시. 현재는 영상에 연동되지 않은 고정 가상 기록이다.
3. 선택 선수의 경기 종료 기록 화면에서 득점, 도움, 출전 시간 확인. 현재는 '경기 종료 기록 미리보기' 버튼으로 열고, 돌아오면 선수 선택이 유지된다.

YouTube 영상과 재생·임베드 방식은 아직 미확정이다. 영상 재생, 포커스 이동, 영상 종료 시 자동 화면 이동, 하이라이트 재생·저장·입력 검증 및 localStorage 유지 기능은 아직 구현하지 않았다. 위 세 기능 구현은 전체 완료 기준 충족과 구분한다.

후속 화면 결정: 경기 시청 화면의 상단 제목은 '축구선수 포커스'로 표시하고, '경기 종료 기록 미리보기' 버튼의 높이는 확인된 기본 높이 48px보다 5px 큰 53px로 한다.

확인 결과: `dart format lib test`, `flutter analyze`, `flutter test` 통과(테스트 3개). `flutter run -d chrome --web-port=7357`으로 Chrome 실행 성공. 화면 접근 권한이 없어 Chrome 화면 조작과 개발자 도구 콘솔 확인은 수행하지 못했다.

Chrome 직접 확인 방법:

1. 선수 칩을 차례로 누른다. 한 명만 선택되고 선택 선수 이름이 바뀌어야 한다.
2. 아무개는 8.4 km / 2골 / 어시스트 1개 / 패스 32회, 누군가는 10.2 km / 0골 / 2개 / 68회, 어떤이는 7.6 km / 0골 / 0개 / 45회인지 확인한다.
3. 누군가를 선택하고 '경기 종료 기록 미리보기'를 누른다. 누군가의 기록에 0골 / 도움 2개 / 출전 시간 85분이 보여야 한다. '선수 선택으로 돌아가기'를 누르고 위로 스크롤하면 누군가의 선택이 유지되어야 한다.
4. 개발자 도구 Console에서 앱 관련 빨간 오류가 없는지 확인한다.
