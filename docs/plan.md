# 앱 기획서

## 1. 앱 이름

화면 상단 제목은 '축구선수 포커스'다.

## 2. 사용자 (누가 쓰나)

- 축구 경기에서 특정 선수의 움직임을 집중해서 보고 싶은 사용자.
- 경기 종료 후 관심 선수의 기록과 하이라이트를 확인하고, 주요 장면에 설명을 붙여 저장하고 싶은 사용자.
- 첫 구현은 Chrome 브라우저에서 사용하는 Flutter Web 앱으로 만든다.

## 3. 해결할 문제 (왜 필요한가)

경기 영상에서 관심 선수가 어디에 있는지 계속 찾기 어렵고, 그 선수의 경기 기록과 주요 장면을 한곳에서 확인하고 싶다. 사용자가 선수를 선택하면 선수 주위의 포커스 테두리가 움직임을 따라 이동하고, 경기 종료 후 기록과 하이라이트를 보여준다.

최종 목표는 실제 실시간 경기 영상에서 선수를 추적하는 서비스다. 현재 영상 예시는 사용자가 지정한 실제 경기 YouTube 하이라이트를 공식 임베드로 재생한다. 2026-10-01 사용자 결정으로 선수 이름과 확인된 이 경기 기록을 실제 자료로 바꿨다. 아르다 귈러의 포커스 대상은 영상 속 튀르키예 10번이며, 확인한 구간의 위치를 수동으로 기록한다.

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)

### 꼭 필요한 기능

- 이 경기에 출전한 실제 선수 선택.
- 사용자가 지정한 YouTube 경기 하이라이트 재생으로 시청 시연.
- 영상 재생 시간과 미리 정의한 선수 위치 데이터에 맞춰 이동하는 포커스 테두리.
- 시청 중 선택 선수의 경기 정보 표시.
- 경기 종료 후 선택 선수의 득점, 도움, 출전 시간 표시.
- 선택 선수의 하이라이트 예시 영상 재생.
- 앱에 포함된 하이라이트 예시 영상 선택, 설명 입력, 저장.
- 저장한 영상 참조와 설명을 보여주는 저장 목록.
- 브라우저 로컬 저장소를 이용해 같은 브라우저와 같은 주소에서 새로고침 후에도 저장 항목 유지.
- 영상 미선택 또는 설명이 비어 있거나 공백뿐인 경우 오류 안내 및 저장 거부.

### 있으면 좋은 기능

기존 설계서에서 별도로 정한 선택 기능은 없다. 실제 생중계 연결과 자동 영상 인식은 후속 개발 범위로 둔다.

## 5. 화면 구성 (위에서 아래 순서)

기존 설계서의 기능을 바탕으로 다음 순서로 구성한다.

### 경기 시청 화면

1. 앱 제목과 실제 경기·기록의 출처 안내.
2. 선수 선택 영역.
3. 경기 영상과 선택 선수 주위의 포커스 테두리.
4. 영상 재생 조작 영역.
5. 선택 선수의 경기 정보.

### 경기 종료 화면

1. 경기 종료 안내와 선택 선수 이름.
2. 선택 선수의 득점, 도움, 출전 시간.
3. 하이라이트 선택 영역과 영상 재생 영역.
4. 선택한 하이라이트의 설명 입력란.
5. 저장 버튼과 입력 오류 안내.
6. 저장한 하이라이트 참조와 설명 목록.

## 6. 사용 흐름 (사용자가 하는 행동 순서)

1. Chrome 브라우저에서 앱을 연다.
2. 아르다 귈러 등 관심 선수를 선택한다.
3. 지정한 YouTube 경기 영상을 재생한다.
4. 선택 선수를 따라 이동하는 포커스 테두리와 경기 정보를 보며 시청한다.
5. 경기 종료 후 선택 선수의 득점, 도움, 출전 시간을 확인한다.
6. 하이라이트를 선택해 주요 장면 영상을 재생한다.
7. 저장할 하이라이트 예시 영상을 선택하고 설명을 입력한 뒤 저장한다.
8. 저장 목록에서 영상 참조와 설명을 확인한다.
9. 같은 브라우저에서 같은 주소의 페이지를 새로고침해 저장 항목이 유지되는지 확인한다.

## 7. 만들지 않을 것

- 회원가입.
- 로그인.
- 서버 구축 및 연동.
- 다른 사람과 공유하는 기능.
- 첫 구현에서 실제 생중계 서비스 연결.
- 영상에서 선수를 자동으로 인식하거나 추적하는 기능. 첫 구현은 미리 정의한 위치 데이터를 사용한다.
- 확인되지 않은 실제 경기 수치를 임의로 채우는 기능. 위치는 영상 속 튀르키예 10번을 수동으로 기록한다.
- 영상 파일 자체를 브라우저 로컬 저장소에 저장하는 기능. 하이라이트 영상의 참조와 설명만 저장한다.
- 첫 구현 범위에 별도로 정하지 않은 기능.

구현은 Flutter와 Dart를 사용하며, 직접 작성하는 앱 소스 코드는 `.dart` 파일로 제한한다. 실행에 필요한 Flutter 설정 파일과 영상 자산은 허용한다. 외부 패키지를 사용하면 사용 목적을 한 줄로 설명한다.

## 8. 완료 기준

1. **선수 포커스 이동:** 브라우저에서 '아르다 귈러'를 선택하고 지정한 YouTube 영상을 재생하면, 수동으로 기록한 튀르키예 10번의 위치에 맞춰 포커스 테두리가 이동한다. 위치 미등록 구간에서는 숨긴다. 다른 가상 선수의 대상·위치 데이터는 아직 미정이다.
2. **경기 기록과 하이라이트:** 경기 종료 화면에 '아르다 귈러'의 득점, 도움, 출전 시간이 표시된다. 하이라이트를 누르면 해당 선수의 주요 장면 영상이 재생된다.
3. **저장과 유지:** 앱에 포함된 하이라이트 예시 영상을 선택하고 설명을 입력해 저장하면 저장 목록에 나타난다. 같은 브라우저에서 같은 주소의 페이지를 새로고침한 뒤에도 같은 영상 참조와 설명을 확인할 수 있다.
4. **잘못된 입력 차단:** 영상 미선택, 설명이 빈 문자열인 경우, 설명이 공백뿐인 경우를 각각 확인한다. 저장 버튼을 누르면 오류 안내가 표시되고 저장 목록에 새 항목이 추가되지 않는다.
5. **1분 시청 확인:** Chrome에서 Flutter Web 앱과 지정한 YouTube 영상을 실행한다. '아무개'를 선택해 1분간 시청할 때 영상이 멈추거나 로딩 표시가 나타나지 않고, 등록한 구간에서 포커스 테두리가 위치 데이터에 맞춰 이동한다. 위치 미등록 구간에서는 숨긴다. 실제 생중계 품질은 별도로 검증한다.

## 9. 현재 구현 범위 (2026-09-30 사용자 결정)

먼저 다음 세 기능을 구현했다.

1. 가상 선수 한 명 선택 및 다른 선수로 변경.
2. 선택 선수의 이동 거리, 골, 어시스트, 패스 표시. 현재는 영상에 연동되지 않은 고정 가상 기록이다.
3. 선택 선수의 경기 종료 기록 화면에서 득점, 도움, 출전 시간 확인. 현재는 '경기 종료 기록 미리보기' 버튼으로 열고, 돌아오면 선수 선택이 유지된다.

추가로 사용자가 지정한 [SPOTV FOOTBALL의 튀르키예 vs 이탈리아 하이라이트](https://www.youtube.com/watch?v=9wx0QPdlPc8)를 YouTube iframe 플레이어로 재생하도록 구현했다. 영상 파일은 저장하지 않는다. Chrome에서 앱 안의 플레이어가 열리고 재생 시간이 0초에서 47초까지 진행되는 것을 확인했다. 영상 소유자의 저작권 자체를 확보했다는 뜻은 아니므로 공식 임베드가 허용되는 범위에서만 사용한다. 영상 종료 시 자동 화면 이동은 현재 코드에 구현되어 있다. 하이라이트 재생·저장·입력 검증 및 localStorage 유지 기능은 아직 구현하지 않았다. 현재 구현은 전체 완료 기준 충족과 구분한다.

후속 화면 결정: 경기 시청 화면의 상단 제목은 '축구선수 포커스'로 표시하고, '경기 종료 기록 미리보기' 버튼의 높이는 확인된 기본 높이 48px보다 5px 큰 53px로 한다.

확인 결과: `dart format lib test`, `flutter analyze`, `flutter test` 통과(테스트 3개). `flutter run -d chrome --web-port=7357`으로 Chrome 실행 성공. Chrome에서 YouTube 플레이어를 눌러 재생 시간이 0초에서 47초까지 진행되는 것과 일시정지를 확인했고, 앱 탭의 브라우저 오류 로그는 비어 있었다. 영상 재생 1분 안정성 및 포커스 동작은 아직 검증하지 않았다.

Chrome 직접 확인 방법:

1. 선수 칩을 차례로 누른다. 한 명만 선택되고 선택 선수 이름이 바뀌어야 한다.
2. 아무개는 8.4 km / 2골 / 어시스트 1개 / 패스 32회, 누군가는 10.2 km / 0골 / 2개 / 68회, 어떤이는 7.6 km / 0골 / 0개 / 45회인지 확인한다.
3. 누군가를 선택하고 '경기 종료 기록 미리보기'를 누른다. 누군가의 기록에 0골 / 도움 2개 / 출전 시간 85분이 보여야 한다. '선수 선택으로 돌아가기'를 누르고 위로 스크롤하면 누군가의 선택이 유지되어야 한다.
4. 개발자 도구 Console에서 앱 관련 빨간 오류가 없는지 확인한다.

## 10. 튀르키예 10번 포커스 (2026-09-30 후속 사용자 결정)

- 자동 인식 없이 실제 영상의 시간별 위치를 수동으로 기록하는 방식을 선택했다. 가상 선수 '아무개'를 선택하면 튀르키예 10번에 포커스를 표시하며, 다른 선수는 위치 미등록 안내를 표시한다. 이름·경기 기록은 기존 가상 데이터를 유지한다.
- 지정한 영상을 Chrome에서 일시정지·프레임 이동하며 등번호 10과 연속 움직임을 확인하고, 980×551 영상 영역의 선수 주변 좌표를 기록했다. 등록 구간은 **0:23.5~0:32.0**, **3:09.0~3:17.5**이며 영상 전체의 모든 등장 구간을 기록한 상태는 아니다.
- 두 장면의 데이터를 분리하고 장면 내부에서 좌표를 보간한다. 위치 미등록 구간에서는 테두리를 숨기며, '화면 밖'이라고 단정하지 않는다.
- 테두리는 YouTube 재생 위치를 사용한다. 재생 중 위치 스트림으로 이동하고 일시정지 중 탐색도 확인한다. 테두리만 다시 그려 영상 플레이어를 재생성하지 않으며, 재생 조작을 가리지 않는다.
- 영상 크기에 맞춰 좌표를 비율로 변환하고 좁은 화면의 16:9 영상 여백을 반영한다. 포커스는 앱 안의 영상에 표시한다. YouTube 자체 전체 화면에서는 Flutter 테두리가 함께 확대되지 않는다.
- 새 파일이나 외부 패키지는 추가하지 않았다. 위치 계산, 구간 경계, 탐색, 여백·크기 변경, 클릭 통과 및 기존 선수 선택·기록 화면을 테스트한다.
- 이번 확인: `dart format lib test`, `flutter analyze`, `flutter test`(6개), `git diff --check` 통과. `flutter run -d chrome --web-port=7358`으로 실행했다. Chrome에서 24초 부근과 31초 부근의 포커스, 일시정지 중 탐색 후 위치 갱신, 선수 변경 시 숨김 및 같은 영상 위치에서 복원, 후반 3:10~3:11 부근의 재생 중 이동, 위치 미등록 구간에서 숨김을 확인했다. 영상 종료 후 아무개의 2골·도움 1개·90분 기록 화면으로 자동 이동한 것도 확인했다. 앱 탭 오류 로그는 비어 있었다.
- 남은 사람 확인: 앱 안에서 등록 구간의 테두리 정밀도를 직접 확인하고, 1분 연속 시청 중 영상 멈춤·로딩 유무를 관찰해야 한다. 탐색 후 재생을 재개할 때 잠깐 로딩 표시를 관찰했으므로 1분 무로딩 기준을 통과했다고 표시하지 않는다. 나머지 등장 구간의 위치 등록, 다른 선수 대상 지정·위치 등록, YouTube 자체 전체 화면의 포커스 표시는 완료하지 않았다. 하이라이트 재생·저장 등 다음 기능은 이번에 구현하지 않았다.


## 11. 하이라이트 선택·재생 시도 (2026-09-30, 미완료)

사용자가 포커스 구현을 확인했다고 알려 주었다. 한 기능씩 개발하는 요청에 따라 기존 두 구간의 하이라이트 선택·재생을 구현했다. 아무개의 종료 기록 화면에서 선택하고 다른 가상 선수는 미등록 안내를 표시한다. 첫 번째 골 장면 제목은 튀르키예 10번의 득점을 뜻하지 않으며 경기 기록은 계속 가상 데이터다.

기본 검사: `dart format lib test`, `flutter analyze`, `flutter test`(7개), `git diff --check` 통과. 새 파일·패키지는 추가하지 않았다. Chrome `http://localhost:7359/`에서 두 장면 선택, 해당 시간 부근부터 재생, 결과 화면 유지와 다시 재생은 확인했다. 첫 재생은 구간 끝에서 멈추는 경우가 있었지만 **다시 재생 시 종료 제한을 넘어 영상 끝까지 진행했으므로 미완료**다. 화면에도 종료 제한이 확인 중임을 표시한다.

종료 제한 수정은 세 번 진행했다: 재생기 식별자 분리, 종료 시 탐색 제거, 스트림 대신 0.2초마다 현재 시간 직접 확인. 세 번째 수정 후에도 후반 다시 재생은 3:17.5를 넘어 3:43까지 진행했다. 반복 규칙에 따라 추가 수정은 멈췄다. 오류 로그에는 youtube_player_iframe의 ParallelWaitError와 숫자 응답을 Map으로 변환하지 못하는 TypeError가 기록됐다. Flutter hot restart 중 disposed EngineFlutterView 오류도 터미널에서 관찰했다. 콘솔 무오류 기준을 통과했다고 표시하지 않는다.

원인 후보: 패키지의 iframe 응답 처리와 반복 재생 명령 간 충돌, 두 재생기의 동시 생존, 탐색 후 YouTube 종료 제한 해제 및 시간 조회 명령 지연. 확정 원인은 아직 없다. 다음 해결 방법은 기존 경기 재생기를 결과 화면 진입 시 닫는 방식으로 재생기 하나만 유지하고, 깨끗한 Chrome 실행에서 재현 여부를 확인하는 것이다. 이 구조 변경이나 패키지 버전 변경은 이번에 시도하지 않았다.

사람 확인: 아무개 → 경기 종료 기록 미리보기 → 두 장면 각각 선택 → 영상 재생 → 이 장면 다시 재생 후 지정 종료 시간을 넘는지 확인한다. 현재 알려진 실패 항목이다. 저장·설명 검증·localStorage 유지와 포커스 1분 연속 무로딩 검증은 아직 미구현 또는 미확인이다.

2026-10-01 후속 작업: 사용자의 재개 요청에 따라 결과 화면 진입 전 경기 재생기를 닫고, 하이라이트의 반복 `currentTime` 조회를 위치 스트림 감시로 바꿨다. `dart format lib test`, `flutter analyze`, `flutter test`(7개), `git diff --check`는 통과했고 Chrome에서 앱 실행까지 확인했다. 두 장면의 첫 재생·다시 재생이 지정 종료 시간에 멈추는지와 콘솔 오류 유무는 사람의 Chrome 확인이 남아 있으므로 하이라이트 완료로 표시하지 않는다.

## 12. 하이라이트 저장 (2026-10-01)

아르다 귈러의 두 장면 중 하나를 선택하고 설명을 입력하면 영상 ID·시작/종료 시간·설명만 브라우저 `localStorage`에 저장한다. `shared_preferences_web`이 `localStorage`를 사용한다. 영상 파일은 저장하지 않는다. 영상 미선택, 빈 설명, 공백 설명은 오류를 표시하고 저장하지 않는다. 저장 목록은 종료 기록 화면에 표시한다.

Chrome `http://localhost:7399/`에서 세 입력 오류, 정상 저장, 같은 주소 새로고침 후 목록 유지를 확인했다. 콘솔에는 YouTube iframe의 `SyntaxError: Unexpected number`와 플레이어 초기화 시간 초과 오류가 기록되어 콘솔 무오류 기준은 미통과다. 하이라이트 재생의 종료 시간 제한도 아직 검증되지 않았다.

## 13. 새 YouTube 링크 입력 (2026-10-01)

첫 화면의 'YouTube 영상 추가' 버튼에서 별도 입력 페이지를 열도록 위치를 옮겼다. 이 페이지에서 새 링크와 설명을 저장하고, 목록의 '재생' 버튼으로 전체 영상을 연다. 선수 종료 기록 화면에는 기존 두 장면의 구간 하이라이트만 남긴다. `youtube.com/watch`, `youtu.be`, `shorts`, `embed`, `live`의 HTTPS 주소를 받아 영상 ID만 저장한다. 잘못된 도메인·영상 ID는 오류를 표시하고 저장하지 않는다. 기존 두 구간의 저장·재생 방식은 유지한다.

Chrome `http://localhost:7400/`에서 잘못된 도메인 거부, 사용자가 이미 지정한 영상의 `youtu.be` 주소 입력·저장, 목록의 플레이어 열기, 같은 주소 새로고침 후 유지를 확인했다. 새로 입력한 **다른** YouTube 영상의 실제 재생 가능 여부와 콘솔 무오류는 아직 확인하지 않았다.

후속 위치 수정: Chrome `http://localhost:7401/`에서 첫 화면 버튼 → 영상 추가 페이지의 저장 → 같은 주소 새로고침 후 유지, 선수 종료 기록 화면의 새 링크 입력란 제거를 확인했다. 사용자가 새 영상을 추가하는 곳은 이제 첫 화면에서 접근하는 페이지다.
